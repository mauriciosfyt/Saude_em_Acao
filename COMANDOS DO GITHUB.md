# **COMANDOS DO GITHUB**



#### Clonar Projetos do GitHub:



**Configurando sua Identidade Local:** 

**git config --global user.name "Seu Nome Completo"**: Para configurar seu nome de usuário.

**git config --global user.email "seuemail@exemplo.com"**: Para configurar seu e-mail.

**git config --global --list**: Para verificar se as informações foram salvas.

**git clone --branch <nome-da-branch> <url-do-repositorio>**: Execute o Comando para Clonar a Branch:

#### Atualizar Projeto no Git:


**git status**: Verifica as mudanças no arquivo.

**git add .**: Adiciona os novos arquivos e alterações do arquivos.

**git commit -m ""**: Adciona um commit explicando as alterações feitas no arquivo.

**git push origin nomedabranch**: Envia para o GitHub na branch selecionada.




#### Formato Convencional de Commits:



**feat**: Usado para novas funcionalidades.

**refactor**: Usado para mudanças no código que não alteram a funcionalidade externa.

**fix**: Usado para correções de bugs.

**style**: Usado para formatação, sem mudanças de código.

**chore**: Usado para tarefas de build, configuração, etc.
